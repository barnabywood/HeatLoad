# Sauna Log Website Mockup

Static marketing-site mockup for `saunalogapp.com`.

## Pages

- `index.html` - conversion-focused landing page
- `features.html` - feature overview
- `apple-watch.html` - Apple Watch session flow
- `insights.html` - long-term progress and Insights
- `faq.html` - search-friendly user questions
- `support.html` - installation, HealthKit, purchase and feature-request support

## App Store campaign links

The links use `ct=` campaign tokens so each page can have a distinct acquisition source. Before publishing, create the corresponding campaign links in App Store Connect and replace these URLs with Apple's complete generated links, including the provider token.

Suggested campaign names:

- `website_home`
- `website_hero`
- `website_features`
- `website_watch`
- `website_insights`
- `website_faq`
- `website_support`

The App Store ID used here is `6759159351`.
