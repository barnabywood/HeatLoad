# Heat Load Brand Direction

## Visual concept
- Theme: thermal contrast (dry ember heat vs humid steam)
- Feel: premium training tool, not spa decoration

## Colors
- `Ember`: #EA572E
- `Steam`: #248FA3
- `Charcoal`: #171A21
- `Sand`: #F7E6CF

## Typography recommendation
- iOS: `SF Pro Rounded` titles + `SF Pro Text` body
- Watch: `SF Compact Rounded`

## Icon concept
- Base: dark charcoal circle/squircle
- Mark: split teardrop/heat-wave glyph in ember + steam
- Accent: subtle inner glow

## Icon production checklist
1. Design 1024x1024 in Figma/Sketch.
2. Export flat PNG with no transparency.
3. Add to `Assets.xcassets/AppIcon` for iOS and watchOS sets.

## UI motion
- Timer transitions: spring animation
- Session end: pulse + haptic
- Paywall reveal: slide-up with blur
